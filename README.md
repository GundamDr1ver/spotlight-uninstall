# 聚焦卸载

为系统聚焦中唯一的 App 结果显示“卸载”按钮。点击后核对应用名称和路径，确认后将应用移到废纸篓。

## 界面

- 一个置顶窗口：应用名称、版本、GitHub 链接、开机自启和辅助功能权限。
- 两项权限分别由用户点击申请；授权状态自动更新，授权成功后按钮禁用。
- 关闭窗口后后台运行，不保留 Dock 或菜单栏图标。登录时静默启动，手动打开应用时显示权限窗口。
- 无启用/停用开关，不记录搜索内容，无联网服务。

## 卸载行为

- 优先将按钮放在 App 结果行的原有搜索 / Tab 提示左侧；空间不足时放到聚焦窗口下方。
- 只处理 `/Applications` 和 `~/Applications` 中的应用包，不清理配置、缓存或其他文件。
- 应用正在运行时提示先退出；不自动结束进程。
- 系统应用、本工具自身、符号链接、应用包内部的嵌套 App，以及名称无法唯一匹配的应用不显示按钮。
- 依赖聚焦的辅助功能结构；系统界面变化可能需要适配。当前已在 macOS 27 验证，构建最低系统版本为 macOS 26，面向 Apple 芯片。

## 开发

原生 Swift / AppKit，使用系统 ServiceManagement 管理登录启动，无额外依赖。

运行 `./build.sh`：先执行启动事件、路径边界、名称歧义和按钮布局测试，再构建、签名并打包。产物为 `dist/SpotlightUninstall-1.0.0-arm64.zip`，临时应用路径记录在 `.build/app-path`。
